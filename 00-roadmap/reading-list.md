## How to read a paper

1. Read the title and abstract.
2. Write the problem in one sentence.
3. Write the baseline in one sentence.
4. Identify the claimed contribution.
5. Examine the main figure or table.
6. Read the method.
7. Read the experiments and limitations.
8. Write five lines: problem, idea, result, limitation, question.
