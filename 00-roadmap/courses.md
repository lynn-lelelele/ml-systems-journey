# Practical English Courses

Recommended in this order. Prefer free or audit options before paying.

## Start now

### 1. CS50P — Introduction to Programming with Python

- Link: https://cs50.harvard.edu/python/
- Why it fits: clear English, short lectures, hands-on problem sets, no C required.
- Use it as the main Python course.
- Recommended pace: one week per CS50P week, but slow down when needed.
- Evidence: complete the problem sets and publish one final project.

### 2. Python for Everybody

- Link: https://www.py4e.com/
- Why it fits: slower and friendlier than CS50P; strong options for beginners who freeze on difficult assignments.
- Use it as a fallback or supplement, not as a second full-time course.
- Evidence: complete the exercises and one data-processing mini project.

### 3. Automate the Boring Stuff with Python

- Link: https://automatetheboringstuff.com/
- Why it fits: immediately practical; teaches file handling, web requests, spreadsheets, and automation.
- Use selected chapters after Python fundamentals are comfortable.
- Evidence: automate one repetitive task and document it.

## Tools and computer fundamentals

### 4. MIT Missing Semester

- Link: https://missing.csail.mit.edu/
- Why it fits: teaches the shell, scripting, Git, debugging, and tools that university courses often assume you know.
- Recommended pace: one lecture per week.
- Evidence: use Git, shell scripts, and debugging tools in a real project.

### 5. Learn Git Branching

- Link: https://learngitbranching.js.org/
- Why it fits: interactive and visual, with very little English reading required.
- Evidence: complete the main and remote sections.

## Mathematics

### 6. 3Blue1Brown — Essence of Linear Algebra

- Link: https://www.3blue1brown.com/topics/linear-algebra
- Why it fits: visual explanations make linear algebra concrete before formal university courses.
- Evidence: explain vectors, matrix multiplication, determinants, and eigenvectors in your own words.

### 7. Khan Academy — Probability and Statistics

- Link: https://www.khanacademy.org/math/statistics-probability
- Why it fits: gradual English, many examples, and immediate practice.
- Evidence: write a short note explaining expectation, variance, conditional probability, and Bayes' theorem.

## Machine learning after Python and NumPy

### 8. Kaggle Learn

- Link: https://www.kaggle.com/learn
- Recommended courses:
  - Python
  - Pandas
  - Intro to Machine Learning
  - Intermediate Machine Learning
- Why it fits: short, practical, and project-oriented.
- Evidence: complete one notebook with a baseline and a written evaluation.

### 9. Machine Learning Specialization — Andrew Ng

- Link: https://www.coursera.org/specializations/machine-learning-introduction
- Why it fits: beginner-friendly explanations and practical labs.
- Start only after Python, NumPy, and basic probability are comfortable.
- Audit if necessary; do not pay before finishing the free prerequisites.

## Deep learning after classical ML

### 10. PyTorch Official Tutorials

- Link: https://pytorch.org/tutorials/
- Why it fits: official, concise, and directly usable.
- Evidence: train, evaluate, save, and reload a small neural network.

### 11. Practical Deep Learning for Coders — fast.ai

- Link: https://course.fast.ai/
- Why it fits: top-down and project-oriented, but it assumes some Python ability.
- Start only after completing CS50P or equivalent.

## Later: ML systems

### 12. Machine Learning Systems open book

- Link: https://mlsysbook.ai/
- Why it fits: connects ML, hardware, performance, and deployment.
- Start after the first model-serving project.

## How to study an English course

1. Watch with English subtitles, not Chinese subtitles.
2. Reduce the speed to 0.75x or 0.9x if needed.
3. Pause after each section and write three English bullet points.
4. Complete every coding exercise rather than only watching.
5. Keep a vocabulary file with technical terms, not general vocabulary.
6. After each week, record a 2-minute English summary.
7. If you cannot explain the code without the video, you have not learned it yet.
