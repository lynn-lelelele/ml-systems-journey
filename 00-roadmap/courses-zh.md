# 中文课程与搜索关键词

原则：中文课用来降低理解门槛，代码、变量名、README 和项目说明尽量使用英文。

## 现在只学这些

### 1. 嵩天《Python语言程序设计》

- 平台：中国大学MOOC、哔哩哔哩
- 搜索关键词：`嵩天 Python语言程序设计`
- 为什么适合：大学课程结构完整，发音清楚，适合从零建立 Python 基础
- 学完标准：能独立写函数、类和文件处理程序，并完成课程练习

### 2. MIT《计算机教育中缺失的一课》中文版

- 网站：https://missing-semester-cn.github.io/
- 搜索关键词：`计算机教育中缺失的一课 中文`
- 为什么适合：补命令行、Shell、Git、调试和工具使用
- 学完标准：能熟练使用终端、Git 和基础脚本

### 3. 宋浩《线性代数》

- 平台：哔哩哔哩
- 搜索关键词：`宋浩 线性代数`
- 为什么适合：节奏接地气，适合基础一般的学生先建立完整概念
- 学完标准：理解向量、矩阵、线性变换、行列式和特征值

## Python 备选课程

### 黑马程序员 Python 入门

- 搜索关键词：`黑马程序员 Python 入门教程`
- 适合谁：喜欢跟着项目反复练习，需要比大学课程更详细的讲解
- 注意事项：课程很长，只选择基础、函数、面向对象、文件和异常部分

### 小甲鱼《零基础入门学习Python》

- 搜索关键词：`小甲鱼 零基础入门学习Python`
- 适合谁：完全零基础，希望讲解轻松
- 注意事项：发布时间较早，遇到旧版本差异时以官方文档为准

### 廖雪峰 Python 教程

- 网站：https://liaoxuefeng.com/books/python/introduction/index.html
- 搜索关键词：`廖雪峰 Python 教程`
- 适合谁：更喜欢看文字和查漏补缺
- 注意事项：不要只读，必须跟着敲代码

## 数学

### 宋浩《高等数学》

- 搜索关键词：`宋浩 高等数学`
- 重点：极限、导数、偏导数、梯度和最优化基础

### 宋浩《概率论与数理统计》

- 搜索关键词：`宋浩 概率论与数理统计`
- 重点：随机变量、期望、方差、条件概率和贝叶斯

### 3Blue1Brown 线性代数中文版

- 搜索关键词：`3Blue1Brown 线性代数 中文`
- 适合：正式学习前先建立直觉

## C 语言和计算机基础

### 翁恺《程序设计入门—C语言》

- 平台：中国大学MOOC
- 搜索关键词：`翁恺 C语言 程序设计入门`
- 开始时间：2027 年学习大学课程后，或 Python 基础稳定后
- 为什么适合：大学教师讲解，适合真正从零理解 C

### 陈越、何钦铭《数据结构》

- 平台：中国大学MOOC
- 搜索关键词：`陈越 数据结构`
- 开始时间：掌握 C 或 Python 基础后
- 注意：数据结构必须手写代码，不能只看视频

### 王道数据结构

- 搜索关键词：`王道 数据结构`
- 适合：需要系统刷题和应对考试
- 注意：偏应试，作为补充而不是唯一课程

## 机器学习和深度学习

### 吴恩达《机器学习》

- 搜索关键词：`吴恩达 机器学习 中文字幕`
- 开始时间：Python、NumPy 和基础概率完成后
- 为什么适合：概念解释清楚，适合第一次接触机器学习

### 李宏毅《机器学习》

- 搜索关键词：`李宏毅 机器学习`
- 开始时间：有 Python、线代和概率基础后
- 为什么适合：中文讲解，覆盖深度学习、Transformer 和生成模型
- 注意：内容更新快，要选择与你当前学习目标接近的年份

### 李沐《动手学深度学习》

- 网站：https://zh.d2l.ai/
- 搜索关键词：`跟李沐学AI 动手学深度学习`
- 开始时间：完成基础 Python 和小型机器学习项目后
- 为什么适合：理论、代码和实验结合，适合作为长期主线
