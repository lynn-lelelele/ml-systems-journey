# ML Systems Journey

A structured learning repository for building the foundations required to work on **Machine Learning Systems**: training infrastructure, inference serving, performance engineering, and scalable ML platforms.

## Goal

- **2027 S1:** Start BSc Computer Science at the University of Auckland.
- **2029:** Complete the three-year BSc with strong foundations and project evidence.
- **2030:** Complete BSc(Hons) and apply for funded postgraduate research.
- **2031:** Begin a funded MPhil/PhD in Hong Kong focused on ML systems.
- **Long term:** Build a Hong Kong career in ML infrastructure and eventually return to Shenzhen.

## Current stage

This repository starts before university. The current phase is deliberately foundational:

- Python that supports complete, tested projects
- Linear algebra, probability, calculus, and optimisation
- Linux, Git, debugging, and reproducible workflows
- Clear project documentation and benchmark results

Advanced topics such as CUDA, distributed training, and custom kernels are intentionally deferred.

## Rules

1. Finish one project before starting another.
2. Every project must include a README, setup steps, reproducible commands, results, and limitations.
3. Prefer measuring and explaining over copying tutorial code.
4. Do not learn CUDA or distributed training before the prerequisites are stable.
5. Commit small changes with meaningful messages.
